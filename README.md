# Search Highlight App

A React app that lets users search through articles and highlights the matching keyword in the results.

## How to run

1. Make sure you have Node.js installed
2. Clone the repository:
   git clone https://github.com/marc-hajjar/search-highlight-app.git
3. Go into the project folder:
   cd search-highlight-app
4. Install dependencies:
   npm install
5. Start the app:
   npm start
6. Open your browser and go to http://localhost:3000
